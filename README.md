# 北邮研究生后台选课脚本

一个用于北京邮电大学研究生选课系统的 Tampermonkey（篡改猴）用户脚本。配置课程编号后，脚本会在选课页面查找目标课程，打开选择班级的 iframe 弹窗，并尝试点击“选”按钮。

脚本在浏览器的选课页面中运行，使用时需保持浏览器和该页面打开。

**已实测环境：Microsoft Edge + Tampermonkey + 北邮研究生选课系统。** 其他浏览器及本科选课系统尚未验证。

## 功能

- 按课程编号匹配当前页面中的目标课程。
- 在课程状态包含“正在选课”时，尝试打开班级选择窗口。
- 查找 iframe 弹窗中的“选”按钮并触发点击。
- 按配置的间隔刷新页面，重新检测课程状态。
- 在浏览器控制台输出匹配、弹窗查找及点击过程。
- 单文件脚本，无需部署服务器或安装项目依赖。

> 当前版本在找到并点击“选”后停止自身的刷新计时器。请在系统中核对选课结果；停止刷新本身不代表选课成功。

## 快速开始

### 1. 安装 Tampermonkey

通过 [Tampermonkey 官网](https://www.tampermonkey.net/) 选择 Microsoft Edge 对应的扩展并安装。

如果扩展提示缺少用户脚本运行权限，按照 [Tampermonkey 官方权限说明](https://www.tampermonkey.net/faq.php?q=Q209) 完成设置。

### 2. 添加脚本

1. 打开本仓库中的 [bupt-course-helper.user.js](./bupt-course-helper.user.js)，复制完整内容。
2. 点击浏览器中的 Tampermonkey 图标，选择“添加新脚本”（或同类菜单项）。
3. 删除编辑器中的默认模板，粘贴脚本。
4. 按下一节修改课程编号和刷新间隔，然后保存。

请先完成配置，再打开需要执行脚本的选课页面。

### 3. 配置目标课程

在脚本开头找到：

```javascript
const targetCourseIds = ["3131101546"];
```

将示例编号替换成你要选择的课程编号。编号应与课程列表中的显示一致，并保留引号，例如：

```javascript
const targetCourseIds = ["你的课程编号"];
```

支持填写多个课程编号：

```javascript
const targetCourseIds = ["课程编号一", "课程编号二"];
```

脚本按**当前页面课程行的顺序**检查目标，找到并点击某门课的“选”按钮后即结束本轮并停止刷新。多个编号表示多个候选目标，不代表会连续完成所有课程的选课。

### 4. 配置刷新间隔

```javascript
const refreshInterval = 1.5 * 1000;
```

单位为毫秒，当前默认值为 **1.5 秒**。例如，改为 5 秒：

```javascript
const refreshInterval = 5 * 1000;
```

此计时器在脚本启动时开始运行，不会等待弹窗处理完成。如果页面或弹窗加载较慢，可以调大间隔，避免处理过程中刷新页面。

### 5. 开始使用

1. 自行登录北邮研究生选课系统。
2. 进入课程列表，确保目标课程已经显示在当前页面。
3. 确认 Tampermonkey 中的脚本已启用，必要时刷新一次页面使配置生效。
4. 等待脚本检测课程并尝试操作。
5. 在系统的选课结果或已选课程列表中核对结果，并处理仍需手动确认的提示。

脚本没有单独的“开始”按钮：在匹配的页面加载并执行后，就会开始检测。

### 6. 停止脚本

在 Tampermonkey 中关闭本脚本，然后刷新或关闭当前选课页面。仅关闭扩展开关，已经在当前页面运行的计时器可能仍会继续工作；重新加载页面才能停止该次运行。

## 工作流程

```text
选课页面加载
    ↓
扫描当前页面中的课程行
    ↓
匹配课程编号及“正在选课”状态
    ↓
点击选择班级的入口
    ↓
等待 iframe 弹窗，查找“选”按钮
    ↓
找到并点击 → 停止自身刷新计时器 → 手动核对选课结果

若尚未找到并点击：刷新计时器到期后重新加载页面，再次检测。
刷新计时器与以上检测流程同时运行。
```

## 适用范围与当前行为

| 项目 | 说明 |
| --- | --- |
| 已实测浏览器 | Microsoft Edge，具体版本暂未记录 |
| 已实测脚本管理器 | Tampermonkey（篡改猴），具体版本暂未记录 |
| 已实测系统 | 北京邮电大学研究生选课系统 |
| 脚本版本 | `3.0`，沿用脚本中的版本号 |
| 页面匹配规则 | `*://*/xsxk/*`，目前按路径匹配，未限定学校域名 |
| 检测范围 | 当前文档中已经加载的课程行，不会自动翻页或搜索课程 |
| 班级选择 | 点击所找到的 iframe 中第一个可见、文本为“选”的匹配按钮 |
| 停止条件 | 找到并点击“选”按钮，不自动验证最终选课结果 |

当前版本依赖课程表格的列顺序、页面按钮样式以及可访问的 iframe 内容。如果系统页面调整，可能需要重新适配。脚本不会根据教师、上课时间或班级编号筛选；对班级有要求时，请先确认弹窗中的排列和目标班级。

## 常见问题

### 脚本没有启动

检查脚本是否已保存并启用、扩展是否具备当前站点的运行权限，以及页面地址是否符合 `*://*/xsxk/*`。保存脚本或修改配置后，重新加载选课页面。

### 页面一直刷新，但没有点击目标课程

检查课程编号是否与列表中的显示完全一致、目标课程是否已出现在当前页面，以及状态文字是否包含“正在选课”。页面加载较慢时，尝试适当调大刷新间隔。

### 打开了弹窗，却没有点击“选”

当前脚本依赖 iframe 弹窗及 `span.l-btn-text` 按钮结构。弹窗加载较慢、页面存在其他 iframe，或系统修改按钮结构时，可能无法定位到目标。可以提供控制台日志和脱敏后的相关页面片段进行排查。

### 停止刷新了，但是课程没有选上

当前停止条件是“已点击按钮”。人数已满、时间冲突、额外确认等情况仍需要查看系统提示。处理完提示并确认需要再次尝试后，可以重新加载页面。

### 如何查看日志

打开浏览器开发者工具，切换到 Console（控制台）。脚本会输出“页面加载完成”“正在等待 iframe 弹窗出现”“‘选’按钮已点击”等过程信息。需要追踪刷新前的日志时，可开启控制台的“保留日志”选项。
